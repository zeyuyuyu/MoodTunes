# MoodTunes - Your AI Music Mood Journal

MoodTunes is an engaging web app that helps users track their daily moods through music. Users select their current emotion, and the app generates a personalized playlist visualization that grows into a beautiful, interactive 'mood garden' over time. Each mood entry creates a unique musical flower with petals representing songs that match their emotional state.

Key Features:
- Interactive mood selection through an intuitive emotion wheel
- Daily musical visualization of moods as growing flowers
- Weekly and monthly mood patterns shown as garden arrangements
- Share your mood garden on social media
- Mobile-responsive design

Tech Stack:
- HTML5 Canvas for animations
- Web Audio API for sound effects
- Local Storage for mood history
- CSS animations
